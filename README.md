# Renta de personas naturales en Colombia

Proyecto académico de Planeación Tributaria y Auditoría.

- **Asesor de renta** (`index.html`): página web interactiva y estática, publicada con GitHub Pages. Indica si una persona debe declarar renta, calcula la depuración y el impuesto, propone un plan de ahorro, calcula el anticipo (art. 807 ET) y trae una lista de chequeo, tablas y glosario. Los cálculos se hacen en el navegador; no se envían datos.
- **Cartilla** (`cartilla/`): documento en Word con formato APA 7 (`Cartilla_renta_APA.docx`) y su texto en Markdown (`cartilla.md`).

Herramienta orientativa. No reemplaza la revisión de un contador.
